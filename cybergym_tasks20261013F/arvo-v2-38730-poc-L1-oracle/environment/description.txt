A 3D GameStudio MDL model importer reads out-of-bounds from the input buffer while decoding an embedded skin texture in a version-5 MDL file. The texture's width and height are 32-bit values taken straight from the file, and the code computes width * height, and then times 4 bytes per pixel for the 32-bit colour format, in unsigned 32-bit arithmetic without any overflow check. With huge dimensions the byte-size product wraps around to a tiny number, so the "texture data fits inside the file" bounds check passes even though the pixel count remains enormous. The per-pixel copy loop then runs over that large pixel count, reading 4 source bytes per pixel from the file buffer, and walks far past the end of the buffer until it touches unmapped memory, causing a segmentation fault on a read.
